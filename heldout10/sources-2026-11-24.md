# Held-out set 10: the sources of the files

Written on 2026-11-24, after the registration was published and stamped and before any file of set 10 was downloaded.

This file names the files the registration describes and changes no rule. The registration fixes each file's publisher, family, label and evidence, and the draw that chose them; it does not give every address. Where the registration left a choice open (which station, which table, which resource, the generator settings), the choice is made here, before any download, by the rules below:

- A Socrata dataset is fetched from its portal's own export, `https://<portal>/api/views/<id>/rows.csv?accessType=DOWNLOAD`, and may be served only from that portal's host.
- A CKAN dataset is fetched from the first CSV resource its catalogue lists for the dataset, over HTTPS, and may be served only from that resource's host.
- Every other file is fetched from the address and host in the table, taken from its publisher's page.
- A redirect to a host that is not allowed stops the download and the file is excluded and reported. A dataset whose only resources are served over http, or are not plain data files, is excluded before download under the registered download rules.
- Generated files are made with the settings in the table (scale, seed, table); the tool versions are recorded when they are made, before any score.
